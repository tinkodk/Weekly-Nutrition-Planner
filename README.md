# 🥗 תפריט שבועי מאוזן

> אתר עזר לסטודנטית: מזינים את מה שנקנה השבוע, והאתר בונה תפריט שבועי מאוזן — עם מתכונים מלאים ורשימת קניות משלימה.

🔗 **כתובת חיה:** https://tinkodk.github.io/Weekly-Nutrition-Planner/

---

## איך זה עובד

1. **המוצרים שלי** — מזינים את המוצרים שנקנו השבוע (טופס עם קטגוריה + מוצר, או טקסט חופשי מהיר)
2. לחיצה על **"בנו לי תפריט שבועי"** — מנוע פנימי בוחר מתוך מאגר מתכונים קבוע (30 מתכונים: בוקר/צהריים/ערב/נשנוש) את המתכונים שמנצלים הכי הרבה ממה שכבר יש, עם דגש על גיוון וזמן הכנה קצר
3. **התפריט השבועי** — 7 ימים × 4 ארוחות, לחיצה על כל ארוחה פותחת מתכון מלא עם רכיבים (מסומן מה יש ומה חסר), הוראות הכנה, וטווח ערכים תזונתיים משוער
4. **רשימת השלמה** — כל הרכיבים החסרים מכל המתכונים בתפריט, מרוכזים למקום אחד

הממשק דו-לשוני (עברית/אנגלית) עם כפתור החלפה בפינה.

## טכנולוגיה

קובץ HTML בודד (`index.html`) — ללא build, ללא תלויות שרת. הנתונים (המוצרים והתפריט שנוצר) נשמרים ב-`localStorage` של הדפדפן, כך שהם נשארים גם אחרי סגירה/רענון.

הקוד עצמו נשמר ב-Git ומתפרסם דרך GitHub Pages כדי שאפשר יהיה להיכנס לאתר מכל מחשב דרך כתובת URL — לצד זה, הקבצים ממשיכים לשבת גם לוקאלית (בתיקייה הזו, תחת OneDrive).
